## Request a test

Create a Bug in `office/OC`, area
`OC\Excel\Intelligence\Copilot\Excel Agent\Automation`, tagged
`AgenticTestRequest`. Keep it open. Use a descriptive title and fill every row
below in the description. The type/tag/state are intake conventions; deployment
must explicitly approve them. Do not mark a request Fixed just to enter the
existing resolved-bug loop.

| Field | What users fill in |
| --- | --- |
| Starting context | <Where the workflow starts and what already exists; or Standard starting state> |
| Input files / data | <Attach files, provide links, or Agent may create synthetic inputs. Include essential characteristics> |
| Steps / prompts | <Ordered actions/prompts, preceding turns and confirmation responses; no selectors or implementation details> |
| Expected result | <Concrete observable outcomes and acceptable variation> |
| Constraints / special rules | <What must not change or happen, important definitions; or None> |

No credentials or private data in public examples. Attachments and links remain
references until their access and use are approved. Synthetic-input permission
covers test data only, not fabricated source evidence or a claim of live success.
A submission requests review; it does not authorize a worker, publish a PR,
change product behavior or bypass a repository's validation policy.
